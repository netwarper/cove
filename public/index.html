                            ⚙️ Settings

                            Change passphrase

                            Recovery key

                            If you lose your passphrase, a recovery key is the only way back in. Regenerating invalidates the old one.

                            Biometric unlock (this device)

                            Re-unlock with Touch ID / Windows Hello / a device passkey after your session times out — no retyping your passphrase. Your passphrase still works and stays required on any device that isn't enrolled. This stores a device-bound wrapped key; the key only leaves the authenticator after a biometric check, so a copied data folder still can't unlock without your device.

                            Auto-lock & sessions

                            Locks Cove on this device after you've been idle; unlock with your passphrase or biometric.

                            How long your unlocked session survives while you're away (tab closed or asleep). It refreshes with use; after this long you'll re-enter your passphrase.

                            This instance

                            The durable local address is set at launch (node server.js --set-domain <name>) so it never drifts.

                            Data location

                            Where your encrypted notes are stored. Point this at a Google Drive, Dropbox, iCloud or Box sync folder to keep your notes on the cloud and in sync across devices. Everything stays end-to-end encrypted — the sync service only ever sees ciphertext.

                            Changing this only records the new location — restart the app for it to take effect, and copy or move your existing data folder to the new path first if you want to keep your notes.

                            Display

                            Image text (OCR)

                            When you paste or attach a screenshot, Cove reads any text in it on your device (nothing is uploaded) so the image turns up in search. Runs in the background the first time it loads a small local engine.

                            Meeting transcription

                            Recording always stays on this machine (saved as an encrypted attachment). Transcription is optional: point it at a local Whisper server to stay fully private, or a cloud provider (audio for transcription is then sent there). Leave the endpoint blank to record without transcribing.

                            Running a local Whisper server is opt-in — nothing is installed for you. See docs/local-whisper.md for a 2-minute setup (whisper.cpp / faster-whisper), then click below.

                            Inbox — send yourself tasks (Slack, etc.)

                            Drop a .txt/.md/.json file into the inbox folder — via Zapier, Make, or a Cloudflare Worker — and each line becomes a task in the chosen workspace, even if this Mac was asleep (it lands next time you unlock). Full setup in docs/slack-inbox.md.

                            Slack — send yourself an agenda

                            Post your due & overdue tasks to Slack via an Incoming Webhook (create one at api.slack.com → Incoming Webhooks and paste the URL). Auto-send only fires while the app is open and unlocked.

                            Backup & restore

                            Download encrypted backup

                            One file containing every note — still encrypted. Restore it on a fresh machine, then unlock with your existing passphrase.

                            Verify a backup (restore drill)

                            Prove a backup file actually decrypts with your current key — before you ever need it. Nothing is imported or changed; every entry is just decrypt-checked.

                            No file chosen

                            Restore

                            Only works on a fresh install with no vault yet. Copy your backup file’s contents here or use a fresh session.

                            No file chosen

                            Export this workspace

                            Download every note in the current workspace as a ZIP.

                            Export for AI (ChatGPT / Claude)

                            Clean Markdown you can upload as knowledge/research to an AI assistant. Export the current workspace or a tag, as one combined file or a ZIP with one file per note.

                            Export whole vault (offline site)

                            A single read-only HTML file containing every note, task, and image across all workspaces — decrypts on-device with your passphrase, no server or network. Open it from Google Drive / Box / Files anywhere. A fresh copy is also saved into your data folder as meeting-notes-viewer.html.

                            Verify data integrity

                            Decrypt-checks every stored file and reports any corruption (e.g. from an interrupted cloud sync).

                            🕐 Version history

                            Snapshots are kept automatically (up to 20). Restoring first snapshots the current version, so nothing is lost.
