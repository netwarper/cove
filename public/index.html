                      Passphrase & recovery

                      Change passphrase

                      Recovery key

                      If you lose your passphrase, a recovery key is the only way back in. Regenerating invalidates the old one.

                      This instance

                      The durable local address is set at launch (node server.js --set-domain <name>) so it never drifts.

                      Display

                      Meeting transcription

                      Recording always stays on this machine (saved as an encrypted attachment). Transcription is optional: point it at a local Whisper server to stay fully private, or a cloud provider (audio for transcription is then sent there). Leave the endpoint blank to record without transcribing.

                      Backup & restore

                      Download encrypted backup

                      One file containing every note — still encrypted. Restore it on a fresh machine, then unlock with your existing passphrase.

                      Restore

                      Only works on a fresh install with no vault yet. Copy your backup file’s contents here or use a fresh session.

                      Export this workspace

                      Download every note in the current workspace as a ZIP.

                      Offline viewer (for your phone)

                      A single read-only HTML file that decrypts on-device with your passphrase — open it from Google Drive / Box / Files with no server running. A fresh copy is also saved into your data folder as meeting-notes-viewer.html.

                      Verify data integrity

                      Decrypt-checks every stored file and reports any corruption (e.g. from an interrupted cloud sync).

                      🕐 Version history

                      Snapshots are kept automatically (up to 20). Restoring first snapshots the current version, so nothing is lost.
